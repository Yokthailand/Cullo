# Cullo

โปรแกรม Windows สำหรับคัดรูปกิจกรรมโรงเรียนที่ถ่ายมาเป็นร้อยเป็นพันรูป ตัดรูปเบลอและรูปหลับตาออกให้อัตโนมัติ แล้วให้คนตรวจซ้ำก่อนส่งออกเป็นสองโฟลเดอร์ `ผ่าน` กับ `คัดออก`

ทำงานออฟไลน์ทั้งหมด รูปไม่ถูกส่งออกจากเครื่อง และไม่แตะ ย้าย หรือลบไฟล์ต้นฉบับ

## ใช้งาน

1. ดาวน์โหลด `Cullo.zip` จากหน้า [Releases](../../releases) แล้วแตกไฟล์
2. เปิด `Cullo\Cullo.exe` (ไม่ต้องลง Python)
3. เลือกโฟลเดอร์รูป JPG ถ้าแยกโฟลเดอร์ย่อยตามกล้อง โปรแกรมจะเทียบความคมแยกกล้องให้
4. รอวิเคราะห์ แล้วไล่ดูแท็บ `คัดออก` กด **P** (ผ่าน) หรือ **X** (คัดออก) แก้รายรูป
5. กด `ส่งออกรูป` ได้โฟลเดอร์ `<ชื่อโฟลเดอร์>_คัดแล้ว` ที่มี `ผ่าน/`, `คัดออก/` และ `รายงาน.csv`

| คีย์ | ทำอะไร |
|---|---|
| P / X | ผ่าน / คัดออก |
| Space | สลับผ่าน-คัดออก |
| ลูกศร | เลื่อนรูป |
| Enter หรือดับเบิลคลิก | ดูภาพใหญ่ (Z ซูม 100%, F แสดงกรอบหน้า) |
| B | เก็บใบที่ดีที่สุดของกลุ่มช็อตรัว คัดที่เหลือออก |
| Ctrl+Z | เลิกทำ |

## ทำอะไรได้

- **ตรวจรูปเบลอ** จากความคมของหน้าคนเด่น เทียบกับค่ากลางของกล้องตัวเดียวกัน ไม่ใช่ความคมทั้งภาพ จึงไม่คัดรูปที่ฉากหลังเบลอโดยตั้งใจ
- **ตรวจหลับตา** ด้วย FaceLandmarker (blendshape)
- **เลือก "คนเด่นที่สุด"** ในภาพ ด้วยขนาดหน้าและความใกล้กลางภาพ และไม่ตัดสินจากหน้าคนข้างหลังเมื่อตัวเอกหันหลัง
- **จัดกลุ่มรูปช็อตรัว** จากเวลาถ่าย (EXIF) และความคล้ายของภาพ แล้วแนะนำใบที่ดีที่สุด
- ปรับความเข้มงวด 3 ระดับ (ผ่อนปรน / ปกติ / เข้มงวด) แล้วผลเปลี่ยนทันที เลือกได้ว่าจะตรวจอะไรบ้าง
- นับรูปที่ตรวจแล้ว และเตือนก่อนส่งออกถ้ายังไม่ได้ดูรูปที่คัดออก
- `รายงาน.csv` บันทึกคะแนน เหตุผล และรูปที่แก้ด้วยมือ

ข้อจำกัด: การตรวจ "หน้าตลก" ยังไม่แม่น (ปิดเป็นค่าเริ่มต้น เปิดเองได้ ป้าย "ทดลอง") และหัวเราะตาหยีอาจถูกนับเป็นหลับตา แนะนำให้ไล่ดูแท็บ `คัดออก` ทุกครั้งก่อนส่งออก

## รันจากซอร์ส

ต้องใช้ Python 3.12

```bash
pip install -r requirements.txt
python app.py
```

โหมดบรรทัดคำสั่ง (ไม่เปิดหน้าต่าง):

```bash
python app.py "<โฟลเดอร์รูป>" ปกติ        # ระดับ: ผ่อนปรน | ปกติ | เข้มงวด, ต่อท้าย all = ตรวจทุกคนในภาพ
```

ทดสอบ: `python -m pytest -q`

สร้าง .exe: `.\build.ps1` (ได้ `dist\Cullo\Cullo.exe` และ zip; ใส่ `-Out <โฟลเดอร์>` ถ้ายังเปิดโปรแกรมเก่าอยู่)

## โครงโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | หน้าต่างโปรแกรม (CustomTkinter) |
| `scorer.py` | วิเคราะห์รูปทีละใบ: ความคม, ตรวจหน้า/คน, สีหน้า, เลือกคนเด่น |
| `judge.py` | ตัดสินผ่าน/คัดออก (สูตร logistic regression 2 ตัวแปร) |
| `config.py` | เกณฑ์ 3 ระดับและค่าสัมประสิทธิ์ของสูตร |
| `pipeline.py` | สแกนโฟลเดอร์ วิเคราะห์ขนาน ส่งออก และเขียนรายงาน |
| `bursts.py` | จัดกลุ่มรูปช็อตรัว |
| `gallery.py`, `thumbs.py`, `icons.py`, `theme.py` | กริดรูปย่อและหน้าตา |
| `models/` | โมเดล MediaPipe (ตรวจหน้า, จุดใบหน้า, ตรวจคน) |
| `dev-tools/refit_from_reports.py` | ปรับค่าสูตรใหม่จาก `รายงาน.csv` ที่คนตรวจแล้ว (ต้องใช้ scikit-learn) |

## ปรับสูตรจากข้อมูลของโรงเรียนเอง

รายงาน.csv ที่ส่งออกจากแอปบันทึกว่ารูปไหน "ตรวจแล้ว" และรูปไหน "แก้ด้วยมือ" เอาไปฝึกสูตรใหม่ได้:

```bash
python dev-tools/refit_from_reports.py "<รายงาน.csv>" ["<รายงาน.csv>" ...]
```

ควรมีรูปที่ตรวจแล้วอย่างน้อย ~200 รูป และมีทั้งผ่านกับคัดออกฝั่งละ 20 รูปขึ้นไป แล้วนำค่าที่ได้ไปแทนใน `config.py`

## โมเดลที่ใช้

โมเดลจาก [MediaPipe](https://ai.google.dev/edge/mediapipe) (Google, Apache-2.0): `blaze_face_short_range.tflite`, `face_landmarker.task`, `efficientdet_lite0.tflite`
